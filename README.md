

A Computer Vision project built with Python, OpenCV, and MediaPipe that allows users to draw on a virtual canvas using hand gestures via a webcam.


- Real-time hand tracking and finger gesture recognition.
- Color palette selection (Blue, Green, Red, Yellow).
- Clear canvas functionality.
- 
- Python 3.12
- Microsoft Visual C++ Redistributable (x64)
